# ByteBeat 🎵

**ByteBeat** is a modern Android music streaming app powered by YouTube Music, wrapped in a sleek, Apple Music-inspired user interface.

## 🌟 Overview
ByteBeat bridges the gap between YouTube Music's extensive library and Apple Music's elegant design system. Built natively with Jetpack Compose, it offers a fast, fluid, and visually stunning listening experience.

## ✨ Features
* **Apple Music UI Design:** Dark mode theme, smooth transitions, floating mini-player, and pill-style navigation tabs.
* **Powered by YouTube Music:** Stream millions of songs directly from the YouTube Music backend.
* **Modern Android Tech Stack:** Fully written in Kotlin using Jetpack Compose for declarative UI rendering.
